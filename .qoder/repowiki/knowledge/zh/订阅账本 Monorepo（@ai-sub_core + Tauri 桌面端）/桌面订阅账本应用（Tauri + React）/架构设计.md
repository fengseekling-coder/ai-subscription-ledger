本模块采用前后端分离的 Tauri 架构：`src/` 下的 React 前端以 `App.tsx` 为根组件，通过 Tauri 客户端调用 `src-tauri/src/lib.rs` 暴露的命令；Rust 后端在 `main.rs` 中初始化 Tauri 应用并注册数据库、OCR、监控等命令，使用 `db.rs` 管理加密 SQLite 存储，`monitor.rs` 处理系统托盘与定时任务，`ocr.rs` 提供文字识别。前端通过 `i18n.ts` 统一国际化、`theme.ts` 管理主题、`storage.ts` 与 `useDebouncedPersistence.ts` 处理本地持久化，所有 UI 组件（Dashboard、BillsView、PendingView、StatsView 及各类 Modal）由 App 统一编排，并通过 Tauri 命令与 Rust 层交互。构建流程由 `vite.config.ts` 驱动前端打包，`tauri.conf.json` 配置应用元数据与权限，`Cargo.toml` 管理 Rust 依赖。
