模块由三个文件构成应用外壳：
- `main.tsx` 是 React 18 的启动入口，通过 `createRoot` 将 `<App />` 渲染到 `#root`，并包裹在 `<StrictMode>` 中。
- `App.tsx` 是单一根组件，集中管理全局 `AppState`（订阅行、账单、监控配置等），通过 `useMemo` 派生出 summary/pending/bills/entries 等只读数据，并通过 `commit` 回调统一更新状态。
- 视图层按 `mode`（subs/expired/bills/pending/stats）条件渲染 `Dashboard`、`SubTable`、`BillsView`、`PendingView`、`StatsView` 等子组件；弹窗类（`SubscriptionFormModal`、`BillFormModal`、`DueDatePickerModal`、`SettingsModal`、`MonitorModal`）以受控形式挂载。
- 与 Tauri 原生能力的交互集中在几个自定义 hook：`useTrayMenu` 调用 `invoke('update_tray_menu')` 更新系统托盘，`useWindowCloseHandler` 拦截窗口关闭并先 flush 持久化，`useNavigation` 监听 `navigate` 事件，`useRenewReminders` 处理续费提醒开关。
- 数据流：`loadAppState` 异步加载 → `setState` → `useDebouncedPersistence` 防抖落盘；后台 `monitor-updated` 事件触发后重新拉取状态。
- `styles.css` 定义完整的 CSS 设计令牌（`:root` 变量）、浅色/深色主题（通过 `@media prefers-color-scheme` 和 `data-theme="dark"` 双路径），以及所有 UI 组件样式。
