- 全局状态通过单个 `useState<AppState | null>` 管理，变更统一走 `commit(next)` 回调，避免分散 setState。
- 派生数据一律使用 `useMemo` 计算（如 `computeSummary`、`sortedBills`、`visibleRowEntries`），依赖 `[state]` 保证缓存失效。
- 副作用通过独立自定义 hook 封装（`useTrayMenu`、`useWindowCloseHandler`、`useNavigation`、`useNotice`、`useDebouncedPersistence`），保持 App 主体逻辑内聚。
- 弹窗组件采用受控模式：通过布尔 state（如 `addModalOpen`、`showSettings`）控制显隐，配合 `onClose` 回调关闭。
- 国际化通过 `resolveLang` + `tFor(lang)` 获取翻译函数，所有文案从 `tr.app.*` / `tr.nav.*` 等命名空间读取。
- 样式采用 BEM 风格类名（如 `topbar__inner`、`modal__panel`、`form-field__hint`），并通过 CSS 变量集中管理颜色、间距、圆角等设计令牌。
