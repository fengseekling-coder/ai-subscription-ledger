- React Hook 中读取可变外部状态一律通过 `useRef` 保存并在 effect 中同步更新，避免将 state 放入 useEffect 依赖导致频繁重跑。
- 异步副作用统一采用 `try/catch` 包裹并在失败时回置脏标记（如 `dirty.current = true`），保证错误可恢复。
- 运行时环境判断通过顶层 `isBrowser()` 或 `typeof window !== 'undefined'` 守卫，使同一份代码同时兼容浏览器预览与 Tauri 打包环境。
- 国际化字符串以 `Dict` 接口约束，每个字段支持普通字符串或 `(param) => string` 的插值函数，按语言分别定义 zh/en 两套对象。
- 主题配置采用键名枚举（`AccentKey`）+ 预设映射表（`ACCENTS`）模式，非法值回退到默认 green，保持 UI 一致性。
