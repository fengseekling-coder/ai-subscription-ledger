本模块由五个相互独立的横向能力文件组成，均位于 `apps/desktop/src/` 根目录，仅依赖上层 React 组件与 `@ai-sub/core` 核心类型：
- `storage.ts`：定义 Dto 与 AppState 的序列化桥接，通过 `isBrowser()` 判断运行环境——浏览器 dev 预览返回 `browserDemoState()` 演示数据，Tauri 打包后通过 `invoke("get_app_state" / "set_app_state")` 与 Rust 后端通信。
- `useDebouncedPersistence.ts`：React Hook，基于 `setTimeout` 实现 200ms 防抖落盘，并通过 `beforeunload` 与 `visibilitychange` 事件保证窗口隐藏/卸载时补写；维护 `dirty` 标记避免首次加载的原样回写。
- `useRenewReminders.ts`：React Hook，使用 `pendingRenewItems` 计算待续费项，通过 Tauri Notification 插件发送系统通知，权限请求失败时降级为应用内 `showNotice` 提示。
- `i18n.ts`：集中管理 zh-CN/en 两套 `Dict` 字典，提供 `detectSystemLang`、`resolveLang`、`tFor` 三个入口函数，支持 `auto` 跟随系统语言。
- `theme.ts`：定义 `Appearance`、`AccentKey`、`ThemeMode` 类型及 6 种 accent 预设（green/blue/indigo/teal/violet/slate），通过 `applyAppearance` 向 `:root` 注入 CSS 变量并设置 `data-theme`。
- `utils/dateUtils.ts`：纯函数式日期工具，提供 ISO↔Date 转换、中英双语日期/月份/星期格式化、日历网格生成等，复用 `@ai-sub/core` 的 `formatDate`。

依赖方向单向向下：Hook → storage/i18n/theme/utils，无循环依赖；所有副作用（文件系统、通知、DOM）都被封装在各自文件中，对外仅暴露纯函数或 Hook。
