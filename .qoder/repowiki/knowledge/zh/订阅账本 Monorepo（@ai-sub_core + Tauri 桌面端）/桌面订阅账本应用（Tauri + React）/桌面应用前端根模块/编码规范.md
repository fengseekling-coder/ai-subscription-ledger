- 所有跨模块共享的 AppState 及其类型从 @ai-sub/core 导入，App 是唯一持有并派生数据的组件。
- UI 状态（mode/editIndex/addModalOpen 等）集中在 App 中用 useState 管理，子组件仅接收 props 回调。
- 弹窗组件统一通过布尔开关 + draft 对象控制显示，提交走 onCommit(state) 回调而非直接 setState。
- 用户反馈统一通过 showNotice(text, danger?) 呈现 toast，危险消息延迟 5s，普通消息 1.6s。
- Tauri 调用使用 invoke/listen API，并在非 Tauri 环境（浏览器预览）通过 window.__TAURI_INTERNALS__ 守卫跳过。
