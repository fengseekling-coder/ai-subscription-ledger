- 组件统一使用 `memo(function Component(...) { ... })` 包裹导出，避免不必要的重渲染。
- 所有用户交互通过 props 回调（如 `onToggle`、`onChange`、`onClose`）上抛，组件本身不持有业务状态。
- 本地化文本通过 `resolveLang(language)` + `tFor(lang).xxx` 获取字典，组件不直接拼接多语言字符串。
- CSS 类名遵循 BEM 命名规范，使用 `--` 表示修饰符（如 `due-badge--overdue`、`cal-picker__day--selected`）。
- 图标通过集中式的 `paths` 映射表管理，新增图标只需在 `IconName` 联合类型和 `paths` 对象中追加即可。
