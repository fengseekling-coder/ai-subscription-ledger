模块由三类独立组件构成，彼此无内部依赖，仅通过 `@ai-sub/core` 类型和 `./i18n`、`./utils/dateUtils` 等上层工具进行横向引用：
- `SubTable.tsx`：订阅列表展示组件，导出 `SubTable`、`SubTableRow`、`ReadCell` 三个 memo 化的子组件以及 `confirmUnrenewedOrDelete` 确认对话框辅助函数；通过 `SubTableHandlers` 接口以回调形式接收所有交互事件，保持纯展示职责。
- `CalendarPicker.tsx`：受控/非受控双模式的日期选择器，内部维护 `viewYear/viewMonth/internalOpen` 状态，支持外部 `isOpen` 控制并通过 `onOpen/onClose` 回调同步父级状态。
- `ui/Icon.tsx`：基于 SVG path 的轻量图标系统，通过 `IconName` 联合类型约束可用图标，并提供 `ModalCloseButton` 复用 close 图标。
- `ui/ModalShell.tsx`：模态框通用外壳，封装 ESC 关闭、遮罩点击关闭及标准 header/body/footer 布局，配合 `FormFooter` 提供表单底部按钮区。
依赖方向单向向上：本模块不反向依赖业务页面，仅消费 `@ai-sub/core` 的类型定义（如 `AppState`、`SubscriptionRow`）和本地化工具。
