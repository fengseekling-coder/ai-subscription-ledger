- 组件均为函数式 React 组件，通过解构 props 接收 `state`、`onCommit`、`language` 等参数，不维护自身 state（除 Dashboard 的预算编辑临时状态外）。
- 状态变更一律调用 `@ai-sub/core` 导出的纯函数（如 `setBudget`、`deleteBill`、`renewRow`、`markUnrenewed`），再通过 `onCommit(next)` 向上提交新状态，避免在组件内直接修改 state。
- 国际化统一通过 `resolveLang(language)` 解析语言后调用 `tFor(lang).xxx` 获取命名空间下的翻译键，禁止硬编码文案。
- 金额显示统一使用 `fmtMoney`，费用字符串统一使用 `feeDisplayParts` 拆分为主货币与约价，保证美元符号不被误显示为人民币符号。
- CSS 类名采用 BEM 风格命名（如 `metric__label`、`summary-strip__item`、`month-bars__track`），并通过条件拼接修饰类（如 `is-ok`、`is-danger`、`is-editing`）表达状态。
- 错误与提示通过回调 `onNotice(text, danger?)` 或 `showNotice(text, danger?)` 上报，而非在组件内自行弹窗。
