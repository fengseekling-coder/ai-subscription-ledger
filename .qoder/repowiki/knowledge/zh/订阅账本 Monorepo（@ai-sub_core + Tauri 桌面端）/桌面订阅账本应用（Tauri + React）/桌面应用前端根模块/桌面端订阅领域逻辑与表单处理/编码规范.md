- 所有业务逻辑以纯函数形式暴露，状态变更通过外部传入的 `commit` 回调触发，避免模块内直接读写全局状态。
- 错误处理采用统一模式：action 返回 `{ error: string }` 或正常结果，由内部 `runAction` 包装后统一调用 `showNotice` 提示并决定是否 commit。
- 可选项与枚举值通过 `as const` 数组导出并同时生成联合类型（如 `PURCHASE_CHANNEL_VALUES` / `PurchaseChannel`），保证类型安全与展示一致性。
- 用户可见文案一律通过 `tFor(resolveLang(state.language))` 按当前语言解析，禁止硬编码中文提示。
