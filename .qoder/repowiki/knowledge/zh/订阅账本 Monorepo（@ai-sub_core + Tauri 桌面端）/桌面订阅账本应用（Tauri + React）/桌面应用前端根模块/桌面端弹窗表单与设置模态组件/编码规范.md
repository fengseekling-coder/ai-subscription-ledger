- 模态组件通过 props 接收 `state`、`onClose`、`onCommit(next: AppState)`，以不可变方式将新状态上抛给父组件，不在组件内部直接修改 state。
- 所有用户可见文案通过 `tFor(resolveLang(language)).xxx` 获取，禁止硬编码字符串。
- 表单组件统一使用 `ModalShell` + `FormFooter` 包裹，或通过自建 overlay 实现点击遮罩关闭行为（`e.target === e.currentTarget && onClose()`）。
- 需要调用后端的异步操作统一通过 `@tauri-apps/api/core` 的 `invoke<T>(command, args)` 发起，错误捕获后转为带 `errorMessage` 的结果对象。
- 日期输入统一复用 `CalendarPicker` 组件，值以 ISO 字符串形式在组件间传递。
- 状态更新使用 `@ai-sub/core` 导出的纯函数（如 `addBillWithDetails`、`updateRow`、`newId`），返回值可能是 `{ error }` 或新 AppState，统一用 `'error' in result` 判断。
