本模块由五个独立的 React 函数式组件构成，每个组件对应一个模态对话框，职责单一且互不依赖：
- `BillFormModal` / `SubscriptionFormModal` / `DueDatePickerModal` 使用统一的 `ModalShell` + `FormFooter` 外壳（来自 `./ui/ModalShell`），通过 `onCommit(next: AppState)` 回调将不可变的状态更新回父级。
- `SettingsModal` 自建 overlay 布局，直接操作语言、主题色、强调色等 Appearance 设置。
- `MonitorModal` 通过 `@tauri-apps/api/core` 的 `invoke` 调用 Rust 后端命令（`check_monitor_cmd`、`check_all_monitors_cmd`、`get_supported_services`），并维护本地 monitors 列表。
- 所有组件均通过 `./i18n` 的 `resolveLang` + `tFor` 获取本地化文案，通过 `./CalendarPicker` 处理日期输入，通过 `@ai-sub/core` 提供的纯函数（如 `addBillWithDetails`、`updateRow`、`newId`）生成新状态。
- 依赖方向单向：组件 → `@ai-sub/core`（状态逻辑）、`./i18n`（国际化）、`./ui/*`（通用 UI）、`@tauri-apps/*`（原生能力）。
