App.tsx 作为单一状态源（AppState），通过 useDebouncedPersistence 从 storage.ts 异步加载并防抖落盘；useMemo 派生出 summary/pending/bills/entries 等只读数据，再按 mode（subs/expired/bills/pending/stats）条件渲染 views 子模块。
- 视图层：Dashboard、BillsView、PendingView、StatsView 仅消费 state 与 onCommit，无副作用。
- 弹窗层：SubscriptionFormModal、BillFormModal、DueDatePickerModal、SettingsModal、MonitorModal 由 App 控制 open/close，通过 onCommit/onNotice 回写状态或提示。
- 共享 UI：SubTable、CalendarPicker、Icon、ModalShell 被多个视图复用。
- 领域逻辑：subTableHandlers.ts + subscriptionFields.ts + categoryLabel.ts 提供行级增删改查与表单默认值。
- 持久化与系统集成：useDebouncedPersistence、useRenewReminders、i18n、theme 在 App 顶层挂载，Tauri 事件（navigate、monitor-updated）与 invoke(update_tray_menu) 在此集中处理。
- main.tsx 仅负责 React 根挂载与样式引入，不承载业务。
