模块以 `main.rs` 为入口，仅调用 `subscription_ledger_lib::run()`；核心逻辑集中在 `lib.rs` 中通过 `#[tauri::command]` 暴露给前端的函数集合，按功能拆分为三个子模块：
- `db.rs`：使用 rusqlite + AES-256-GCM 对 `ledger.db` 中的 JSON 状态进行加密存储，密钥保存在 `.ledger_key`（Unix 0o600、Windows icacls 限制），提供 `load_state`/`save_state` 及对应的 `_in` 目录版本以便测试。
- `monitor.rs`：通过 reqwest 异步调用 OpenAI、Anthropic、Cursor 的公开/内部 API 校验 Key 有效性并汇总结果，支持批量并发（每批最多 3 个）。
- `ocr.rs`：macOS 下通过 objc2 绑定 CoreGraphics + Vision 框架对 RGBA 像素直接 OCR，非 macOS 平台返回错误。

`lib.rs` 还负责 Tauri 应用初始化：注册 notification 和 clipboard-manager 插件、构建系统托盘菜单、启动每 6 小时一次的后台线程调度器（通过 `AtomicBool` 控制退出），并通过 `tauri::generate_handler!` 将命令路由到对应函数。`build.rs` 仅调用 `tauri_build::build()`，打包配置由 `tauri.conf.json` 管理，产物名为 `subscription-ledger`，目标包含 app 与 dmg。
