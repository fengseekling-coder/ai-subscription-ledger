- 所有暴露给前端的函数均使用 `#[tauri::command]` 宏声明，参数通过 AppHandle 或简单 DTO 传递，错误统一以 `Result<T, String>` 形式返回。
- 数据模型使用 serde 的 `#[serde(rename_all = "camelCase")]` 与前端 JSON 字段名保持一致。
- 可测试的纯逻辑都提供 `_in(dir: &Path)` 版本（如 `load_state_in`/`save_state_in`），对外包装函数仅做 AppHandle → 目录转换。
- 平台相关功能通过 `#[cfg(target_os = "macos")]` / `#[cfg(not(target_os = "macos"))]` 条件编译隔离，非 macOS 路径返回明确错误而非静默失败。
- 错误类型采用 thiserror 的 `#[derive(Error)]` 枚举，rusqlite/serde_json/aes_gcm 等下游错误通过 `From` 转换为统一的 `DbError`。
