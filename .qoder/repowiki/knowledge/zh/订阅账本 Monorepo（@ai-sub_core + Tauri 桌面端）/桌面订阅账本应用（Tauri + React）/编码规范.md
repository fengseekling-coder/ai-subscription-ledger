- 前端组件按功能拆分到独立文件（如 BillsView.tsx、SubscriptionFormModal.tsx），通过 App.tsx 统一路由与状态管理
- Tauri 命令在 Rust 侧通过 `#[command]` 宏暴露，前端通过 `invoke` 调用，保持命令式接口风格
- 本地持久化统一通过 `useDebouncedPersistence` Hook 实现，避免重复的 localStorage 读写逻辑
- 国际化文案集中在 `i18n.ts`，组件通过统一的翻译键访问多语言文本
- 测试文件与源文件同名并以 `.test.ts` / `.test.tsx` 后缀并列存放，使用 Vitest 框架
