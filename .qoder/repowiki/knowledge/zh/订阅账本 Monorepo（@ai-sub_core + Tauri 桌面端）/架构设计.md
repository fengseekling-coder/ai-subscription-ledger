根目录作为 monorepo 入口，使用 `workspaces: ["packages/*", "apps/*"]` 管理子包：`packages/core` 提供纯函数式订阅/账单领域逻辑，`apps/desktop` 基于 Tauri 2 将 React 前端与 Rust 后端打包为桌面应用，两者通过 Node 工作空间依赖串联；`scripts/` 中的 parity 脚本在每次 core 改动后比对统计摘要基线，确保 core 与桌面 demo 的统计口径一致；顶层 `eslint.config.js` 统一 TS/React Hooks 规则并跨 packages 与 apps 生效；CI 通过 `npm run check`（test + parity + build）一次性校验所有子模块。
