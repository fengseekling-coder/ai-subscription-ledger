模块以 `src/index.ts` 为唯一对外入口，采用按职责拆分的单文件模块（`actions.ts`、`load.ts`、`views.ts`、`analytics.ts`、`paste.ts`、`money.ts`、`dates.ts`、`normalize.ts`、`rules.ts`、`ids.ts`、`defaults.ts`），并通过 `types.ts` 集中定义 `SubscriptionRow`、`Bill`、`Monitor`、`AppState`、`Summary` 等核心类型。

- 依赖方向单向：`actions.ts` 依赖 `dates`/`money`/`normalize`/`rules`；`load.ts` 依赖 `defaults`/`normalize`/`money`；`analytics.ts` 依赖 `stats`/`rules`/`money`；`paste.ts` 依赖 `normalize`/`money`/`dates`。各工具模块之间无循环依赖。
- 状态管理采用不可变纯函数风格：所有 `actions.*` 函数接收 `AppState` 并返回新状态或 `{ error: string }`，通过 `guardIndex` 统一做索引边界校验。
- 数据加载与迁移集中在 `load.ts`，提供 `createEmptyState`、`createDemoState`、`loadFromJson`，并在内部调用 `ensureSubscribedAtFromRows`、`ensureBillsFromRows` 完成历史数据兼容。
- `views.ts` 仅负责派生视图数据（过滤、排序），不修改状态；`analytics.ts` 基于 `stats.billsForCalendarMonth` 聚合消费统计。
- `paste.ts` 通过 `parsers` 映射表实现插件式解析器扩展（当前支持 `generic-bills-json` 与 `relay-order-text`）。
- 构建产物由 TypeScript 编译到 `dist/`，`package.json` 通过 `exports` 字段暴露 ESM 入口，测试使用 Vitest 在 node 环境运行。
