- 状态变更函数统一接收 `AppState` 作为首参，并返回 `AppState | { error: string }` 联合类型，错误通过对象字面量区分而非抛出异常。
- 所有输入数据在进入领域逻辑前必须经过对应的 `normalize*` 函数（如 `normalizeRow`、`normalizeBill`）进行清洗与类型归一化。
- 日期处理统一通过 `dates.ts` 中的 `formatDate`、`nextRecurringDueDate`、`normalizeDateInput` 等函数，避免直接使用 `new Date()` 字符串拼接。
- 金额计算统一使用 `money.ts` 的 `feeToCnyAmount` / `moneyValue`，禁止直接对原始 fee 字符串进行数值运算。
- 可选参数中需要引用时间的函数统一提供 `ref = new Date()` 形参，便于测试时固定时间基准。
- 对外导出的类型通过 `export type * from "./types.js"` 集中重导出，保持 API 表面整洁。
