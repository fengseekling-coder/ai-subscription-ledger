该模块为纯文档目录，按主题拆分为多份 Markdown：`product.md` 给出用户视角的产品说明与验收标准；`product-mvp.md` 定义 MVP 范围、竞品矩阵、统计口径、数据模型（Subscription/Bill）、历史 v3 JSON 迁移规则与 Phase 0 验收；`product-report.md` 梳理现有功能盘点与导入能力短板，并给出技术架构建议（core 层解析 + Tauri+React 桌面壳）；`beta-survey-and-analytics.md` 提供内测问卷题目、成功指标阈值与埋点事件表；`desktop-mac.md` 记录 macOS 端技术栈（Tauri 2 + React + SQLite）、命令与数据路径；`macos-signing.md` 覆盖本地未签名、Developer ID 签名与公证、Ad-hoc 流程及环境变量；`ios-roadmap.md` 规划 Phase 2 iOS 技术路线（SwiftUI/Tauri Mobile/Capacitor）与跨端数据交换策略。各文档通过交叉引用（如 `./product.md`、`./beta-survey-and-analytics.md`）形成统一的产品知识体系，不依赖代码实现。
