本模块由三类独立脚本与一个 CI 工作流组成，彼此通过 npm 命令和文件系统耦合：
- `scripts/parity-html-core.mjs` 是 Node ESM 脚本，通过 `../packages/core/dist/index.js` 调用 `createDemoState`、`computeSummary`、`pendingRenewItems`、`fmtMoney` 等核心 API 生成摘要报告，并与同目录的 `parity-baseline.json` 快照进行 JSON 规范化比对；支持 `--update` 重写基准和 `PARITY_REF` 环境变量切换参考日期。
- `scripts/sign-macos-app.sh` 基于 `codesign` 对 Tauri 构建产物 `订阅账本.app` 执行 ad-hoc 或指定证书签名并验证。
- `.github/workflows/ci.yml` 定义三个 job：`lint-and-test`（Node 20/22 矩阵，运行 ESLint、core/desktop 测试、类型检查与 parity 守卫）、`build-desktop`（macOS runner 上执行 Rust fmt/clippy/test 并通过 `npm run tauri:build` 打包 .app/.dmg 上传 artifact）、`security-audit`（npm audit + cargo audit）。
依赖方向单向：CI → scripts → packages/core/dist，scripts 不反向依赖上层应用代码。
